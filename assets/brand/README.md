# C4 identity

The mark uses four angular gate segments to form an open C: four controlled crossings and one continuous trace. Deep graphite and steel blue match the website's cold palette.

- Master asset: [`c4-logo.png`](c4-logo.png), 1254 × 1254, transparent PNG.
- Web asset: [`apps/web/public/brand/c4-logo.png`](../../apps/web/public/brand/c4-logo.png).
- Generated with the built-in image generation tool. No external image API or CLI fallback was used.
- Used in the website navigation/footer, favicon, social metadata, and repository README.

## Generation prompt

```text
Use case: logo-brand. Asset type: final standalone brand mark for C4, an open-source evidence-aware AI agent control plane. Design a distinctive minimal geometric symbol expressing four controlled crossings and a continuous trace. A compact square abstract C monogram built from four precise interlocking angular gate segments, with one clean negative-space path through its center. Restrained Swiss modernist identity, cold and rigorous research-software aesthetic, recognizable at 32px. Flat solid deep graphite #253b4d with a subtle steel-blue #6486a0 accent on one segment. Perfectly crisp edges, generous balanced negative space, strong silhouette. Center one large mark occupying about 80 percent of a square canvas. Genuinely transparent background, preserve alpha. No text, no wordmark, no mockup, no gradient, no texture, no shadow, no glow, no 3D, no surrounding frame, no presentation sheet. This is the production logo asset, not an illustration.
```
